J2ME LLM 配置包

完全离线运行。把密钥在安卓手机上填好，生成 .j2cfg，再通过蓝牙发送给 Java 手机导入。

安全提醒：.j2cfg 会以明文保存 API 密钥，CRC 只能发现传输损坏，不能加密。请只在可信设备上操作，蓝牙传输并成功导入后立即删除两台手机上的文件；更推荐使用限额、可撤销的网关令牌。
